# Princess Frecia M. Labra — Portfolio

A responsive, static portfolio website made with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Preview locally
1. Download and unzip this folder.
2. Open `index.html` in a browser.

For a local development server, use the VS Code **Live Server** extension.

## Customize before publishing
- Update the introduction, biography, skills, project titles, and descriptions in `index.html`.
- Replace the sample CSS artwork with your real project images. Put images in `assets/` and use paths such as `assets/project-one.jpg` in `<img>` elements.
- Replace `your.email@example.com` with your actual email address.
- Change colors and typography in the `:root` section at the top of `style.css`.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `my-portfolio`).
2. Upload **all files and folders inside this project folder** to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your live URL will appear in the Pages settings.

Every time you push or upload changes to the selected branch, GitHub Pages will update the site.
